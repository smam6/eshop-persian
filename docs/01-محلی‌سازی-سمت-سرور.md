# گام ۱ — محلی‌سازی سمت سرور (ASP.NET Core)

در این گام، زیرساخت محلی‌سازی به پروژه اضافه شد تا متن‌های رابط کاربری و پیام‌های
API از «منابع» (Resources) خوانده شوند، نه رشته‌های hard-coded درون کد.

## ۱. WebApp (Blazor)

### افزونهٔ `LocalizationExtensions`

فایل جدید `src/WebApp/Extensions/LocalizationExtensions.cs` دو متد توسعه (extension) ارائه می‌کند:

| متد | کاربرد |
| --- | --- |
| `builder.AddPersianLocalization()` | ثبت `AddLocalization`، `AddControllersWithViews().AddViewLocalization().AddDataAnnotationsLocalization()`، `AddRazorPages()` و پیکربندی `RequestLocalizationOptions` |
| `app.UsePersianLocalization()` | فعال‌سازی میانه‌افزار `UseRequestLocalization` با گزینه‌های ثبت‌شده |

نکات پیاده‌سازی:

- **فرهنگ پیش‌فرض:** `fa-IR` — ساخته‌شده از `PersianCultureHelper.GetPersianCulture()`
  تا تقویم هجری شمسی و واحد تومان به‌صورت خودکار در `ToString()`ها اعمال شود.
- **فرهنگ پشتیبانی‌شده:** `en-US` به‌عنوان fallback.
- **زنجیرهٔ تشخیص فرهنگ:** `QueryString` (‏`?culture=fa-IR&uiculture=en-US`) ← `Cookie` ← `Accept-Language`.
  به این ترتیب کاربر می‌تواند با یک پارامتر ساده زبان را عوض کند و انتخابش در کوکی
  `.AspNetCore.Culture` برای درخواست‌های بعدی ذخیره می‌شود.
- `FallBackToParentCultures` و `FallBackToParentUICultures` روشن‌اند تا اگر کلیدی در
  `fa-IR` نبود، به منبع خنثی (انگلیسی) مراجعه شود و کلید خام به کاربر نشان داده نشود.

### `Program.cs`

```csharp
// محلی‌سازی فارسی - فرهنگ پیش‌فرض fa-IR با تقویم شمسی و واحد تومان
builder.AddPersianLocalization();
...
app.UsePersianLocalization();
```

## ۲. فایل‌های منبع

| فایل | توضیح |
| --- | --- |
| `src/WebApp/Resources/SharedResources.cs` | کلاس نشانگر برای `IStringLocalizer<SharedResources>` |
| `src/WebApp/Resources/SharedResources.resx` | ۷۴ کلید، مقدار خنثی (انگلیسی) |
| `src/WebApp/Resources/SharedResources.fa-IR.resx` | معادل فارسیِ همان ۷۴ کلید |

نام منبعِ تولیدشده `eShop.WebApp.Resources.SharedResources` است؛ چون در `WebApp.csproj`
مقدار `RootNamespace` روی `eShop.WebApp` تنظیم شده، فایل resx در پوشهٔ `Resources` دقیقاً
همان نامی را می‌سازد که `IStringLocalizer<SharedResources>` انتظار دارد.

> در برنامهٔ Blazor نیازی به کلاس Designer برای resx نیست؛ کلیدها مستقیماً از طریق
> `IStringLocalizer` خوانده می‌شوند:
>
> ```razor
> @using eShop.WebApp.Resources
> @inject IStringLocalizer<SharedResources> L
>
> <h1>@L["CatalogTitle"]</h1>
> ```

### بسته‌های NuGet

هیچ بسته‌ای لازم نیست. `Microsoft.Extensions.Localization` و
`Microsoft.AspNetCore.Localization` هر دو در `Microsoft.AspNetCore.App`
(فریم‌ورک مشترک ASP.NET Core روی .NET ۱۰) موجودند. در صورت نیاز به بسته‌ای مستقل:

```bash
dotnet add src/WebApp package Microsoft.Extensions.Localization
```

## ۳. لایهٔ API

### `Catalog.API`

پیام‌های خطای این سرویس در بدنهٔ `application/problem+json` به کاربر بازمی‌گردند،
پس محلی‌سازی شدند:

- `builder.Services.AddLocalization(options => options.ResourcesPath = "Resources");`
- `app.UseRequestLocalization(...)` با فرهنگ پیش‌فرض `fa-IR` و پشتیبانی `en-US`.
- `src/Catalog.API/Apis/CatalogApi.cs` به‌جای رشته‌های ثابت، از
  `IStringLocalizer<CatalogApiResources>` استفاده می‌کند:

```csharp
return TypedResults.BadRequest<ProblemDetails>(new()
{
    Detail = localizer[nameof(CatalogApiResources.ItemIdRequired)]
});
...
return TypedResults.NotFound<ProblemDetails>(new()
{
    Detail = localizer["ItemNotFound", id]
});
```

- منابع: `src/Catalog.API/Resources/CatalogApiResources.resx` (انگلیسی) و
  `CatalogApiResources.fa-IR.resx` (فارسی).

### سایر APIها

`Basket.API` یک سرویس gRPC داخلی است و پاسخ مستقیمی به مرورگر نمی‌دهد؛
`Ordering.API` و `Webhooks.API` نیز پیام کاربرپسندی تولید نمی‌کنند
(فقط لاگ‌های تشخیصی). به همین دلیل در آن‌ها رشته‌سازی محلی نشده تا هزینهٔ
بی‌مورد اضافه نشود؛ در عوض متن‌هایی که کاربر می‌بیند در WebApp محلی‌سازی شده‌اند.

## ۴. اعتبارسنجی

```bash
# بررسی XML بودن و هم‌تعدادی کلیدهای دو فایل resx
python3 - <<'PY'
import xml.etree.ElementTree as ET
def keys(p): return [d.get('name') for d in ET.parse(p).getroot().findall('data')]
a = keys('src/WebApp/Resources/SharedResources.resx')
b = keys('src/WebApp/Resources/SharedResources.fa-IR.resx')
assert a == b, set(a) ^ set(b)
print('resx keys OK:', len(a))
PY
```
